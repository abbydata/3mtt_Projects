# 3MTT Data Analysis Projects

This repository contains projects I completed during my data analysis training and certification with 3MTT Nigeria. It reflects my hands-on learning journey in using data analytics tools to solve real-world business problems, explore datasets, and communicate insights effectively.

## About This Repository

The projects in this repository showcase my practical experience with:

- Excel for data cleaning, analysis, visualisation, and reporting
- Power BI for dashboard creation and business reporting
- Python for data analysis, transformation, and visualization
- SQL for querying, managing, and analyzing structured data

I focused on applying data analysis concepts to real-world scenarios, including data exploration, problem framing, cleaning, analysis, visualization, and insight generation.

## What I Learned

Through this training, I developed a strong foundation in the data analysis workflow, including:

- Understanding business problems and translating them into analytical questions
- Working with real datasets and identifying patterns and trends
- Cleaning and preparing data for analysis
- Using tools and techniques to analyze data and derive insights
- Creating visualizations and reports that support decision-making
- Building confidence in using industry-standard analytics tools
